# Sales Performance Analysis

## Overview
This project analyzes sales data to understand performance by region, sales rep, and product.

## Tools Used
- Python
- Pandas
- Google Colab
- Matplotlib

## Key Steps
- Created synthetic sales dataset
- Calculated revenue from unit price and quantity
- Analyzed performance by region and rep
- Visualized trends

## Key Insights
- Top performing region identified
- Best sales rep identified
- Revenue trends analyzed over time
